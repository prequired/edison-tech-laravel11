## 🛠️ Quick Start

```bash
# Verify build
./verify-build.sh

# Install dependencies
composer install --no-dev --optimize-autoloader

# Configure environment
cp .env.example .env

php artisan route:cache
php artisan view:cache

# Deploy with Docker
docker-compose up -d
```
